# 常见问题

## 安装与兼容

- **支持版本**：仅 Minecraft 1.20.1，需 Fabric Loader 0.19.2+ 与 Fabric API 0.92.8+。
- **服务器**：可用，服务端与客户端都要装。
- **Carpet Mod**：默认启用兼容模式，检测到 Carpet 时自动禁用本模组假人功能；如需同时使用，在配置中关闭 `carpetModCompatibility`（可能冲突，建议只用其一）。

## 假人管理

- **创建/删除**：`/bot <名字> spawn` / `/bot <名字> kill`；名字为 3-16 位字母数字下划线，且不与现有玩家重名。
- **数量上限**：默认无限，`maxBotCount` 可限制。
- **死亡**：默认删除；开启 `autoRespawnOnDeath` 会自动重生（回重生点/创建者处，支持跨维度）。
- **保留**：开启 `botPersistence` 后退出重进仍在。
- 假人被视为普通玩家，会加载区块、触发刷怪与进度、获得经验，占用玩家槽位；创建/删除会有"加入/离开游戏"提示。

## 控制假人

- **能做什么**：移动、攻击、使用物品、潜行/跳跃/疾跑、看向、丢物/换手、骑乘、寻路。
- **寻路**：`/bot <名字> goto <x> <y> <z>`（`goto stop` 取消）。v1.3.1 起支持游泳、跨越裂谷、跨维度、危险规避，且不卡服。
- **越障**：`allowBotAutoJump`（默认开）让假人移动时自动跳过 1 格障碍。
- **停止**：`/bot <名字> stop`。
- **背包/末影箱/面板**：**右键假人**打开设置面板 →"打开背包/末影箱"，或用 `/bot <名字> inventory|enderchest|panel`。背包可编辑主物品栏+盔甲+副手并设置手持槽位，改动实时同步。
- **暂不支持**：主动开箱、村民交易、睡觉。

## 指挥棒

- **获取**：两根木棍合成，不可堆叠。
- **用法**：手持时屏幕左上/右上显示信息；`Ctrl+滚轮`切模式，`Alt+滚轮`或`Alt+右键看向假人`选人，`右键看向某处`让假人寻路前往或传送至该处。
- **传送权限**：默认仅手持玩家为创造模式时可传送，开启 `allowBatonTeleportNonCreative` 放开；传送/寻路均支持跨维度。

## 皮肤

- 按 **Mojang API（正版名）→ PNG → Base64 → 默认** 回退。将 64x64/64x32 的 PNG 放入 `skins/` 文件夹（开发环境 `run/skins/`，生产 `.minecraft/skins/`）后重启即随机使用。详见 [皮肤系统](SKINS.md)。

## 配置

- **打开**：按 **B** 键；或右键假人打开其设置面板。
- **修改**：界面 / `/botmod config set <key> <value>` / 手动编辑 `config/my-bot-mod.json`（改后 `/botmod config reload`）。所有配置**立即生效**。
- **重置**：`/botmod config reset` 或界面重置按钮或删除配置文件。

## 故障排除

- **假人不动**：确认下达了 `move`/`goto` 且未 `stop`；可能被卡住，尝试重建。
- **攻击/挖掘无效**：确认面向目标、在攻击距离内；生存挖矿为渐进式（v1.3.1 已修复"挖不动"）。
- **命令用不了**：确认有 OP 权限（或开启 `allowNonOpControlBot`）。
- **模组不加载/崩溃**：确认版本 1.20.1 + Fabric Loader + Fabric API；查看日志/崩溃报告，必要时只装本模组复现后提 Issue。

## 性能

假人较多会有开销：单人建议 ≤10 个，多人按服务器性能调整；可禁用不需要的功能（伤害/饥饿）、限制数量。
