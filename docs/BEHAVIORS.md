# 行为系统（Behaviors）

v1.3.3 起，假人支持**行为脚本**：用外置的图形化编辑器（类 Scratch 积木）编排动作序列，导入游戏后分配给假人执行。

## 快速上手

1. 用浏览器打开仓库中的 **`editor/behavior-editor.html`**（双击即可，离线可用），或直接在**游戏内编辑器**中编写（行为管理界面 → "新建行为"）。
2. 从左侧工具箱/分类面板拖出或选择积木编排行为，填写行为名/描述；需要循环用"永远重复"积木。
3. HTML 编辑器：点击**保存 .json**，把下载的文件放入 **`.minecraft/config/my-bot-mod/behaviors/`**（开发环境 `run/config/my-bot-mod/behaviors/`）；也可点保存旁的**文件夹按钮**直接写入任意目录（会话内记忆所选目录；不支持该能力的浏览器仍走下载）。
   游戏内编辑器：点击**保存**自动写入 behaviors 目录并立即可用；也可在"导出目录"输入框指定任意文件夹导出副本。
4. 游戏内**右键假人** → 面板中点 **行为管理** → 重扫文件夹 → 点击行为加入播放列表 → **▶ 启动**（界面实时刷新，无需退出重进）。
   或用命令：`/bot <名字> behavior assign <文件名.json>` + `/bot <名字> behavior start`。

`editor/examples/` 提供了示例行为（巡逻问候、盘点助手），可直接使用或在编辑器中打开学习。

## 游戏内行为编辑器

行为管理界面的"新建行为"（或可用行为/播放列表行的 ✎ 按钮）打开游戏内编辑器：

- **左侧分类面板**：事件/动作/移动/容器/控制/变量与函数/输出，点击分类切换中部调色板；点击积木即添加到当前语句列表（有参数的会弹出参数表单）。
- **右侧语句列表**：每行提供 ✎ 编辑 / ▲▼ 双向排序 / ✕ 删除；重复/如果/事件等带嵌套体的积木有 → 按钮进入内层编辑，面包屑导航可返回。
- **表达式输入**：参数表单中的表达式支持 数字/文本/布尔/变量/传感器/二元运算/一元运算 七种类型切换，传感器可再嵌套参数。
- **保存与导出**："保存"写入 behaviors 目录（服务端自动校验并重载，结果见聊天栏）；"导出目录"输入框可指定任意文件夹导出副本（相对路径按游戏目录解析）。
- **打开已有行为**：顶部输入文件名点"打开"，或直接从行为管理界面的 ✎ 按钮进入。
- 产物与 HTML 编辑器完全兼容（同一 format=1 JSON），两个编辑器可互换使用。

## 执行模型（Scratch 式多脚本）

- **一个帽子块 = 一个脚本（线程）**：多个帽子块**并联**同时运行，互不阻塞；帽子下的积木链**串联**依次执行。
- 变量全行为共享；等待/寻路/开箱等挂起只影响自己所在的脚本。
- 事件帽子（聊天/广播/血量/实体接近）触发时（重）启动自己的脚本，其他脚本不受影响；含事件帽子的行为会驻留监听不自动结束。
- “发送广播”可跨假人触发所有运行中行为的“当收到广播”帽子（多假人协作）。

## 积木分类（100+ 积木 / 11 分类）

| 分类 | 内容 |
|------|------|
| 事件（金，帽子块） | 当行为启动时、当玩家发送"…"时（chat_sender / chat_message 变量）、当收到广播、当血量低于 X、当附近出现某实体 |
| 动作（黄） | 说话、攻击/使用（单次/持续/间隔）、切槽位、把指定物品拿到手上、丢弃指定物品、看向最近实体、**持续看向跟随实体 / 停止跟随**、换手、丢弃、骑乘/下马 |
| 移动（蓝) | 定向移动、跳跃、潜行、疾跑、看向方向/坐标、转视角、寻路到坐标（阻塞至到达）、取消寻路 |
| 容器（品红） | 打开/关闭容器、取出/放入物品（实际数量存变量）、读取清单、导出清单；传感器：格子数/指定格物品/指定格数量/物品总数。**拟真流程**：够不着会先寻路到附近，再旋转视角看向容器打开（箱盖/声音真实生效），操作完毕或行为结束自动关闭 |
| 选择器（绿） | MC 物品选择器（常用 90+ 物品下拉）、自定义物品 ID、实体选择器（常用 40 实体） |
| 感知（青） | 血量/上限、饥饿、经验、护甲、氧气、坐标、维度、手持物品、自己的名字、在地面/水中/着火/潜行、下雨/白天、指定坐标方块 ID、脚下方块、朝向方位、手持是否为某物、背包是否有某物、正在使用物品、鱼是否上钩、到坐标距离、最近玩家名/距离、最近实体坐标/距离/存在（含末影珍珠等非生物）、背包计数、周围生物数（可按类型过滤）、寻路状态、当日时间 |
| 控制（橙） | 等待、**等待直到条件**、重复 N 次、当…重复、如果/否则、永远重复、**发送广播**、停止本脚本、结束行为、停止一切 |
| 运算（绿） | 四则、乘方、取余、平方根/绝对值/相反数、sin/cos/tan、π/e 等常量、取整、较大/较小值、随机数、比较、逻辑与或非 |
| 文本（绿） | 文本、拼接、长度、包含、子串、第 i 个字符、查找位置、大小写/去空格、为空判断、追加文本 |
| 列表（紫红，1-based） | 新建列表、加入/插入/删除/替换/清空、第 i 项、首/尾/随机项、长度、包含、查找位置、拼接为文本、文本拆分为列表 |
| 变量 | 赋值/增减/读取（全行为共享） |
| 函数（蓝紫） | Blockly 自定义函数（可带参数，递归有深度保护） |
| 输出（紫） | 输出文本到文件、导出背包清单、**原始行输出**（无前缀）、**自定义模板输出**（占位符 `{time}` `{bot}` `{var:变量名}`，格式仅决定扩展名）、**自定义表格输出**（自定义表头 + 逐行追加 CSV）；所有输出均支持 追加/覆盖 写入模式 |

## 外置输出

输出类积木把内容写到 **`.minecraft/my-bot-mod-exports/`**：

- **txt**：追加文本行 `[时间] [假人] 内容`
- **json**：追加 JSON Lines（每行一个对象，扩展名 `.jsonl`）
- **csv**：首次写入表头，之后追加数据行（可直接用表格软件打开）
- **原始行**：直接写入内容本身，不添加时间/假人前缀
- **自定义模板**：模板字符串完全决定每行内容，支持占位符 `{time}`（时间）、`{bot}`（假人名）、`{var:变量名}`（行为变量值）；未知占位符原样保留；格式参数仅决定文件扩展名
- **自定义表格**：自定义表头列（新文件时写入一次）+ 逐行追加自定义列数据（CSV 转义）
- **写入模式**：以上输出均支持 追加（默认）/ 覆盖 两种模式

文件名会自动清洗（拒绝路径穿越），写入异步执行不影响服务器性能。

## 播放列表与运行规则

- 每个假人可分配**多个行为**，按顺序依次执行（播放列表）；列表随假人驻留保存。
- 行为管理界面为**每假人独立**（右键假人面板 → 行为管理），打开期间自动轮询刷新运行状态；顶部状态行实时显示正在执行的行为名与队列进度（第 x/y 个）。
- 播放列表每行提供 ▲▼ 双向排序与移除，底部可一键清空；可用行为支持搜索框按名称过滤，每行 ▶ 可**只跑这一个**（临时执行，不改动播放列表）。
- 手动 `/bot <名字> stop` 或指挥棒下令会**暂停**行为脚本，避免抢控制权。
- 解释器每线程每 tick 有执行预算，无 `等待` 的死循环不会卡服（自动让出）。
- 行为文件解析失败会在行为管理界面/命令中列出错误原因。

## 命令

| 命令 | 说明 |
|------|------|
| `/bot <名字> behavior list` | 列出可用行为与该假人的播放列表 |
| `/bot <名字> behavior assign <文件>` | 加入播放列表 |
| `/bot <名字> behavior unassign <文件>` | 移出播放列表 |
| `/bot <名字> behavior start` / `stop` | 启动 / 停止执行 |
| `/bot <名字> behavior reload` | 重扫行为文件夹 |

## 文件格式（format=1）

行为文件为 JSON：`program` 是运行时执行的语句树（op + 表达式参数 + 嵌套 body/then/else），`blockly` 是编辑器工作区快照（保证再次打开无损还原）。手写 `program` 也可以运行，但建议始终用编辑器生成。
